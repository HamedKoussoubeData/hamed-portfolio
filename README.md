# Portfolio Hamed KOUSSOUBÉ — Installation sur GitHub Pages

## Fichiers inclus

- `index.html` : contenu du portfolio
- `style.css` : mise en forme et version mobile
- `script.js` : menu mobile et animations
- `assets/hamed-koussoube.png` : photo du portfolio

## Fichier à conserver dans le dépôt

Le bouton « Voir le CV » pointe vers `CV-Hamed-Koussoube.pdf`.
Conserve donc le fichier PDF déjà présent à la racine de ton dépôt GitHub.

## Mise à jour du dépôt

1. Ouvre le dépôt `hamed-portfolio` sur GitHub.
2. Clique sur **Add file**, puis **Upload files**.
3. Dépose `index.html`, `style.css`, `script.js` et le dossier `assets`.
4. Confirme le remplacement des anciens fichiers, puis clique sur **Commit changes**.
5. Ne supprime pas `CV-Hamed-Koussoube.pdf`.
6. Attends une à trois minutes puis actualise ton site GitHub Pages.

## Personnalisation rapide

Les couleurs principales sont définies au début de `style.css` dans le bloc `:root`.
Les liens vers les projets GitHub et les textes sont directement modifiables dans `index.html`.
