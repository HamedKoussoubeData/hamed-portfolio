# Portfolio sans dossier assets

## Fichiers à mettre à la racine du dépôt GitHub

- index.html
- style.css
- script.js
- portrait-placeholder.svg
- hamed-koussoube.png
- CV-Hamed-Koussoube.pdf

Le fichier `hamed-koussoube.png` correspond à votre photo professionnelle.
Si la photo n'est pas encore ajoutée, le site affichera automatiquement
`portrait-placeholder.svg`.

## Mise en ligne

1. Décompressez le ZIP.
2. Ouvrez votre dépôt GitHub Pages.
3. Cliquez sur **Add file > Upload files**.
4. Sélectionnez tous les fichiers du dossier décompressé.
5. Ajoutez aussi votre photo sous le nom exact `hamed-koussoube.png`.
6. Ajoutez votre CV sous le nom exact `CV-Hamed-Koussoube.pdf`.
7. Cliquez sur **Commit changes**.

Aucun dossier `assets` n'est nécessaire.
